Singly Linked List Memory Architecture

The Linked List is the Sole Owner of the medicine records. Nodes are dynamically allocated on the heap via new Node.

// Super Simple Singly Linked List (modules/InventoryList.cpp) struct Node { Medicine data; // Real Medicine details Node* next; // Pointer to the next node in heap memory }; void InventoryList::addMedicine(const Medicine& m) { Node* newNode = new Node{m, nullptr}; if (head == nullptr) { head = newNode; return; } Node* temp = head; while (temp->next != nullptr) temp = temp->next; temp->next = newNode; }
Hash Table with Chaining (Size = 10, Formula: ID % 10)

Lookup by Medicine ID is O(1) average. Collisions are handled using Separate Chaining.

Binary Search Tree (Expiry Date Index)

Indexed by Expiry Date (YYYY-MM). In-order traversal (Left -> Root -> Right) visits dates in chronological order!

Circular Array Queue (Capacity = 10)

Handles restock orders via FIFO. Modulo wrap-around (rear + 1) % 10 reuses freed slots.

Teacher Viva & Defense Question Bank
Q1. Why are you using 4 different data structures instead of just one?
Each structure serves a distinct optimal role:
1. Singly Linked List: Stores dynamic master records without array resizing.
2. Hash Table: Provides O(1) instant search and updates by Medicine ID.
3. Binary Search Tree: Provides O(log n) chronological sorting and expiry queries (in-order traversal).
4. Circular Queue: Enforces fair First-In, First-Out (FIFO) processing for supplier restock orders without shifting array items.
Q2. What is the Hash Function and how are collisions handled?
The hash function takes the integer Medicine ID modulo 10:
int index = id % 10;
Collisions are resolved via Separate Chaining: each bucket is the head of a linked list. For instance, IDs 101 and 111 both yield Bucket 1 and form a linked list chain: [111] -> [101] -> NULL.
Q3. Why is the Queue implemented as Circular rather than a normal array?
In a standard linear array queue, dequeuing leaves dead empty slots at the front. Moving elements to index 0 requires O(n) shifts. A circular queue wraps around using modulo arithmetic:
rear = (rear + 1) % 10;
This guarantees both Enqueue and Dequeue remain strictly O(1)!
Q4. How does the BST sort medicines?
The BST organizes nodes where Left Child < Parent < Right Child based on expiry date string.
When we perform an In-Order Traversal (Left -> Root -> Right), it recursively prints the medicines in strictly chronological order from earliest to latest!
